Guideline
  1. Only Excel files in .xls or .xlsx format are supported.
  2. File size must not exceed 5 MB.
  3. The file should not contain more than 5,000 rows.
  4. Use the provided sample template and do not change the column headers or their order.
  5. Mandatory fields include: Parent Name, Phone Number, and Grade.
  6. Entries with the same Parent Name, Phone Number, and Email will be automatically flagged as duplicates.
  7. Phone numbers must contain only digits (no spaces or symbols).
  8. Avoid using special characters like @, #, $, etc., in name fields.
  9. Phone numbers should be exactly 10 digits.
  10. Upload one file at a time. If duplicates or errors are detected, you will be able to download and review them.

Duplicates Detected

Our system scans uploaded enquiry records to detect duplicates based on the following key identifiers:

  • Parent Name: ensures every enquiry is added only once.
  • Phone Number: the parent's primary contact, so it must be unique across enquiries.
  • Email: helps detect the same parent added again under slightly different details.

If matches are found across these fields, the records are grouped under "Duplicates Detected" so you can review and resolve them before importing.

Unique Data

The Unique Enquiries section lists every record that passed the duplicate check successfully. These enquiries are clean, accurate, and ready to be added to your enquiry list.

What makes a record unique?

  • The parent name, phone number, and email are all distinct.
  • No conflict exists with previously added enquiry records.

By validating these key fields, the system ensures every enquiry is distinct and avoids duplicate records.
